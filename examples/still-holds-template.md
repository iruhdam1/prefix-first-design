# still-holds.md — the monthly check

Live products drift away from their briefs. Once a month, 20 minutes, three questions.
Keep this file in the repo next to your brief. One dated entry per check.

---

```
STILL HOLDS? — [Date] — [Product / page]

1. Is the brief still true?
   (Have the users or constraints changed since it was written?)
   [Yes, it holds / No — what changed]

2. Did anything ship that contradicts a locked decision?
   [Nothing / What shipped, and which decision it contradicts]

3. What did we learn that should become a locked decision?
   [New locked decisions — add them to the brief]

Action taken:
   [Brief updated / decision re-locked / nothing needed]
```

---

If question 1 fails two checks in a row, the brief needs a rewrite session —
not another patch. That's a finding, not a failure.

Part of [Prefix-First Design](../README.md) by [Madhuri Maram](https://madhurimaram.com).
